无需安装依赖。在当前项目目录中运行：

```sh
# 添加任务
python3 todo.py add "买牛奶"
python3 todo.py add "阅读 Python 文档"

# 列出全部任务
python3 todo.py list

# 按编号标记完成
python3 todo.py done 1

# 再次查看
python3 todo.py list
```

最后会显示：

```text
[x] 1. 买牛奶
[ ] 2. 阅读 Python 文档
```

每次命令执行后自动退出，添加和完成操作会立即保存到脚本旁的 `tasks.json`。关闭终端后再运行，任务仍然保留；从其他目录通过脚本的绝对路径启动，也会使用同一份数据。查看帮助可运行 `python3 todo.py --help`。
