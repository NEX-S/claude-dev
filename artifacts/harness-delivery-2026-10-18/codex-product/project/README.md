# 本地待办工具

使用 Python 3 标准库，无需安装依赖。每次运行执行一个命令，执行后自动退出。

## 启动与使用

在本项目目录中打开终端：

```sh
python3 todo.py add "买牛奶"
python3 todo.py add "阅读 Python 文档"
python3 todo.py list
python3 todo.py done 1
python3 todo.py list
```

最后一次列出的结果：

```text
[x] 1. 买牛奶
[ ] 2. 阅读 Python 文档
```

- `add "任务内容"`：添加任务，自动分配编号；内容含空格时加引号。
- `list`：按添加顺序列出全部任务，`[ ]` 表示未完成，`[x]` 表示已完成。
- `done 编号`：将指定任务标记完成。重复完成会提示已经完成。
- `python3 todo.py --help`：查看命令帮助。

任务在第一次添加时保存到脚本所在目录的 `tasks.json`，每次变更立即保存。
关闭终端或重新运行后，任务仍然存在。从其他目录使用脚本的绝对路径启动，也会读取同一份数据。
请保留 `tasks.json`；移动工具时，将它与 `todo.py` 一起移动。

空白任务、无效编号或无法读取/保存的数据会给出错误，并以非零状态退出。
工具用于单人在本机依次执行命令，不支持多个进程同时修改任务。
