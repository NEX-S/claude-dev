保留 README 中的现有 CLI、输出、失败语义和 SQLite 数据格式：add TITLE 创建待办并输出整数 ID；list 按 ID 递增输出 JSON 数组，每项恰为 id/title/done，done 为布尔；done ID 完成已有任务；export 按 ID 递增输出 Markdown，每行 - [ ] TITLE 或 - [x] TITLE。数据跨调用持久化。标题保留原始空白和 Unicode，拒绝纯空白标题，不存在的 ID 报错。失败须非零退出、有原始原因的 stderr、严格空 stdout。
